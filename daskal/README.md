# daskal.AI 2.0

Помощник на българския учител: годишни разпределения, уроци, контролни, дейности и процедурни въпроси по актуалните учебни програми на МОН и уредбата (консолидирана към 12.11.2026).

## Структура
```
SKILL.md                         инструкциите (задължителен)
references/tematichna-karta.md   тематична карта на 112 програми, I–XII клас
references/osnova.md             нормативна база, методика, PDF адреси на програмите
references/zakon-*.txt           38 закона и наредби, пълни текстове
scripts/                         търсене в картата и законите, създаване на Word
.claude-plugin/plugin.json       манифест за плъгин (Claude, ChatGPT)
```

## Къде как
| Среда | Как |
|---|---|
| Claude, ChatGPT | Качи архива като **плъгин** |
| Grok | Прикачи архива в разговора |
| Gemini | Skills → Create → Upload → `SKILL.md`, после добави файловете от `references/` (и по желание `scripts/`) |
| DeepSeek и други | Прикачи `SKILL.md` + файловете от `references/`, които са нужни |
| Лимит от 3 файла (BgGPT) | `SKILL.md` + `tematichna-karta.md` + `osnova.md`; закон в следващо съобщение при нужда |

Отваряне: „Действай като даскал“ или директно задачата.

## Обновяване (поне веднъж годишно)
Провери програмите на mon.bg и законите в lex.bg, обнови файловете в `references/`, вдигни `version` в `.claude-plugin/plugin.json`.
